# Still / 无事发生 — PRD

## 目标
Still 记录那些“什么都没发生”的时间，让用户可以在 1 分钟以上的安静时段里暂停产出、结束后留下一条轻量记录，并生成愿意分享的今日报告。

## V1
- Today 首页：开始/结束计时、今日报告、空白日历、累计时间
- 离线优先：计时依赖本地时间戳，刷新/后台恢复不会丢失
- 结束分类：发呆、散步、看窗外、喝水、不知道
- 历史、成就、分享文本与分享卡预览入口
- Supabase 仅用于匿名身份、会话同步和全局聚合；无后端时不伪造数据
- MockAdService 接口预留，V1 不接广告 SDK

## 不做
AI、社交、聊天、复杂排行榜、读取手机使用时间、位置/相机/麦克风/通讯录权限。

## 成功指标
用户完成一次记录后，能在 10 秒内理解今日报告并分享；核心计时在弱网和离线环境可用。
